## 언어와 문제 형식

시작 화면에서 한글·English·Bahasa Melayu와 객관식·주관식·혼합식을 선택합니다. 선택은 기기에 저장됩니다. 객관식은 보기가 작성된 신규 66개/전체 1,193개에서 출제하며, 주관식은 전체 문항을 보기 없이 풀 수 있습니다. 혼합식은 가능한 경우 절반씩 섞고 후보가 부족하면 안내합니다. 신규 영어 질문·정답은 직접 작성했고 해설은 핵심 요약입니다. 말레이어는 자동 번역 초안을 포함하며 전 문항의 언어·신학 감수는 받지 않았습니다. 번역 수정 원본과 검증 도구는 전체 ZIP에 포함됩니다.
